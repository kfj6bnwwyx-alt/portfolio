Getting started

Three steps to connected.

1

Install the daemon

On your Mac, run the menu-bar app or npx code-connector. It needs Node ≥ 20 and Tailscale.

2

Scan the pairing QR

The Mac shows a pairing QR. Scan it with the iPhone app to mint this device’s revokable token.

3

Work from anywhere

Your sessions appear. Approve, watch, and review from anywhere on your tailnet.

FAQ

Common questions.

How do I set it up?

Two parts. On your Mac, install the daemon — either the native menu-bar app or npx code-connector — which needs Node ≥ 20 and Tailscale. It walks you through Tailscale if it isn’t up yet, wires the Claude Code hooks, and ends with a pairing QR. On your iPhone or iPad, open Code Connector and scan that QR (or tap Connect on your Mac’s card). Your sessions then appear.

Do I really need Tailscale?

Yes, by default. Tailscale (WireGuard) is both the transport and the encryption layer — the app↔daemon traffic itself is plain HTTP/WS, so the encrypted tunnel is what protects it. The daemon binds to its Tailscale address, and the phone reaches it there, so both discovery paths ride the same encrypted tunnel. That’s why it’s required, not merely recommended. Install the Tailscale app on the phone under the same account and keep it connected.

Is my code private?

Yes. There is no Code Connector cloud, account, analytics, or telemetry. The app talks only to your own Mac, over your own Tailscale network, device-to-Mac. Nothing about your code, terminals, or notifications transits a Code Connector server — because there isn’t one. Push notifications are sent by your own daemon directly to Apple’s push service using your own APNs key. Pairing tokens live in the iOS Keychain. See the Privacy Policy for the full model.

Can I pair more than one device?

Yes — mint one pairing token per phone or iPad, and revoke any of them individually. One thing to note: push notifications go to a single APNs device token, so only the most recently paired phone receives pushes. All paired devices can still connect, watch, and review.

How do I revoke a device’s access?

Each pairing has its own bearer token. List and revoke them from the daemon (for example, npm run tokens -- list and npm run tokens -- revoke). The daemon hot-reloads the change within about five seconds — no restart, and no re-pairing of your other devices.

Which agents work with it?

Claude Code is the first-class, zero-config integration and is wired automatically. Any other CLI agent — Codex, Aider, or a bare shell — works too: it’s surfaced through a generic hook system and tagged by its source name. Note that an agent running in a desk terminal outside a Code Connector tmux session won’t generate status updates or pushes.

What does it cost?

There is no subscription and no Code Connector account. You own the daemon, the network, and the data. Tailscale has its own free and paid tiers, and sending push notifications requires a paid Apple Developer account plus a one-time APNs key setup — everything else works without it.

The app can’t connect to my Mac. What should I check?
  • Tailscale is up on both ends. The Mac and the phone must be signed into the same tailnet and connected.
  • The Mac is awake and reachable. The daemon can’t wake a sleeping machine — keep the Mac awake, or use a keep-awake option.
  • The daemon is running. Start it from the menu-bar app, or check your npx code-connector process.
  • The pairing is still valid. If you revoked this device’s token, re-pair by scanning a fresh QR.
  • MagicDNS. Pairing prefers the Tailscale MagicDNS name and falls back to the raw Tailscale IP automatically if the name can’t resolve on the phone.
Can I edit files or commit from the phone?

Not directly — by design. The file browser and diffs are read-only. To change anything, you ask the agent to do it in the session. The phone is a window into your Mac, not a second editor.
